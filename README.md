# 📊 Sales Data Exploratory Analysis

## Overview

This project was completed as part of my Data Analytics studies with Mission Ready.

The purpose of the project was to explore and analyse a sales dataset using Python and identify patterns, relationships and useful insights from the data.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Microsoft Fabric

## 📈 Skills Demonstrated

- Exploratory Data Analysis (EDA)
- Data cleaning and exploration
- Summary statistics
- Data visualisation
- Correlation analysis
- Identifying patterns and relationships in data
- Communicating insights from data

## 📁 Project

The Jupyter Notebook in this repository contains the analysis, Python code, visualisations and findings completed during the project.
